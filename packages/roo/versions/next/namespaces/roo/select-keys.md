<h1><code>select-keys</code></h1>
<div class="symbol-metadata"><span>Since <code>0.1.0</code></span></div>
</header>

Returns a new map containing only the specified keys.

<hr class="signature-divider">

```roo
(select-keys map keys)
```

<hr class="signature-divider">

### Usage:

```roo
(select-keys {:a 1 :b 2 :c 3} [:a :c]) => {:a 1 :c 3}
```

<hr class="signature-divider">

## Signature:

```roo
(select-keys map keys)
```

| Arg  | Description          |
| ---- | -------------------- |
| map  | The source map.      |
| keys | Seq of keys to keep. |

### Returns:

A new map containing entries for the requested keys found in the
source.
