<h1><code>redraw!</code></h1>
</header>

Rewrite widgets one at a time, starting at the current cursor row.

<hr class="signature-divider">

```roo
(redraw! session ids prefix)
```

<hr class="signature-divider">

`prefix` (typically a move-up escape sequence) is attached to the very
first row of the very first widget only - see `print-lines!`.

<hr class="signature-divider">

## Signature:

```roo
(redraw! session ids prefix)
```

| Arg     | Description |
| ------- | ----------- |
| session |             |
| ids     |             |
| prefix  |             |
