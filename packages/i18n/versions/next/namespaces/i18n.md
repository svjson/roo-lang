# i18n

| Symbol                                           | Summary                                                                    |
| ------------------------------------------------ | -------------------------------------------------------------------------- |
| [`catalog`](i18n/catalog.html)                   | Create a translation catalog.                                              |
| [`default-locale`](i18n/default-locale.html)     | Return a catalog's fallback locale.                                        |
| [`fallback-message`](i18n/fallback-message.html) | Look up a message in the catalog's default locale.                         |
| [`locale-messages`](i18n/locale-messages.html)   | Return every message declared for a locale.                                |
| [`message`](i18n/message.html)                   | Look up one message without applying fallback behavior.                    |
| [`missing?`](i18n/missing-p.html)                | Test whether a locale lacks an exact translation.                          |
| [`translate`](i18n/translate.html)               | Translate a key using locale, default-locale, and key-text fallback order. |
| [`translated?`](i18n/translated-p.html)          | Test whether a locale contains an exact translation.                       |
| [`translations`](i18n/translations.html)         | Return a catalog's translation table.                                      |
